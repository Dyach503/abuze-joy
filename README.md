# Abuze Joy — VPN Router + DPI Bypass

Десктопное приложение для Windows: выборочная маршрутизация трафика через VPN и
обход блокировок (DPI bypass).

> Автор: **Dyach503**

## Возможности

- **Выборочный VPN** — через VPN идут только выбранные домены, IP и приложения.
- **Полный VPN** — весь трафик системы через VPN.
- **Обход DPI (Zapret)** — обход блокировок без VPN, через [winws2](https://github.com/bol-van/zapret2).
- **Конструктор стратегий Zapret2** — собирай стратегии обхода визуально, без командной строки.

## Требования

- **Windows 10/11** x64
- **Права администратора** — обязательно
- Для VPN-режимов — настроенный VLESS-сервер (VLESS-ключ)

## Запуск (портативная версия)

1. Скачайте zip из [Releases](https://github.com/Dyach503/abuze-joy/releases) и распакуйте в любую папку.
2. Запустите `AbuzeJoy.exe` **от имени администратора** (ПКМ → «Запуск от имени администратора»).
3. Все данные (маршруты, настройки, логи) хранятся в папке `data/` рядом с `AbuzeJoy.exe` —
   приложение ничего не пишет за пределами своей папки и ничего не передаёт на сторонние сервисы.

```
AbuzeJoy/
├── AbuzeJoy.exe
├── resources/      ← бинарники и конфиги (sing-box, winws2, zapret2)
└── data/           ← создаётся при первом запуске: маршруты, настройки, логи
```

## Режимы работы

Режим выбирается на главной странице (**Главная**).

| Режим | Что делает |
|-------|------------|
| **Off** | Всё выключено, трафик идёт напрямую. |
| **Zapret** | Только обход DPI (winws2) для доменов из «Маршруты Zapret». Без VPN. |
| **VPN Selective** | Через VPN идут только домены/IP/приложения из «Маршруты VPN», остальное — напрямую. |
| **VPN+Zapret** | Выборочный VPN и обход DPI одновременно. |
| **VPN Full** | Весь трафик системы через VPN (TUN). |

Все VPN- и TUN-режимы работают через [sing-box](https://github.com/SagerNet/sing-box).

## Быстрый старт

1. **Конфиг VPN** — вставьте ссылку `vless://...` в поле импорта и нажмите «Импорт».
   Поля заполнятся автоматически.
2. **Маршруты Zapret** — добавьте домены для обхода блокировок (или импортируйте список из файла).
3. **Маршруты VPN** — добавьте домены/IP/приложения, которые должны идти через VPN.
4. **Главная** — выберите режим.

Подробности — на странице **Справка** внутри приложения.

## Настройка Zapret

На странице **Настройка Zapret** доступны:

- **Готовые пресеты** — Normal / Normal+ / Normal+Discord. Если не уверены — начните с Normal+Discord.
- **Конструктор** — визуальная сборка собственной стратегии из профилей (фильтр трафика +
  действия обхода: `fake`, `multisplit`, `multidisorder`, `fakedsplit`, `rst`) с живым
  предпросмотром аргументов winws2.
- **Автотест** — автоматически проверяет пресеты на вашем домене и выбирает самый быстрый.

Описание синтаксиса winws2 — в `resources/zapret2/manual.md`.

## Сборка из исходников

Требуется **Node.js 18+** и **Rust** (stable).

1. Положите runtime-бинарники в `resources/` — см. [RELEASE_BINARIES.md](RELEASE_BINARIES.md)
   (`sing-box.exe`, `wintun.dll`, `winws2.exe`).
2. Соберите портативную папку:

   ```powershell
   ./build-portable.ps1
   ```

   Результат — `dist-portable/AbuzeJoy/` (`AbuzeJoy.exe` + `resources/`).

Для разработки: `npm install && npm run tauri dev`.

## Частые проблемы

**«requires administrator privileges»**
→ Запустите `AbuzeJoy.exe` от имени администратора.

**VPN не работает, логи sing-box пустые**
→ Проверьте настройки сервера на странице «Конфиг VPN» и наличие доменов в «Маршруты VPN».
Смотрите вкладку sing-box на странице «Логи».

**Zapret (winws2) не стартует**
→ Запустите от администратора. Антивирус может мешать — добавьте `winws2.exe` в исключения.
Смотрите вкладку Zapret на странице «Логи».

**Обход не помогает для конкретного сайта**
→ Добавьте домен в «Маршруты Zapret», попробуйте другой пресет или соберите свой профиль в конструкторе.
